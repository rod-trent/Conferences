# Deck source

[`build/deck.js`](build/deck.js) generates the deck in [`../SlideDecks/`](../SlideDecks/) with [pptxgenjs](https://gitbrains.github.io/PptxGenJS/). It's a structured deck: a theme, layouts with placeholders, sections, and speaker notes on every slide. That means it also edits cleanly in PowerPoint.

## Rebuild

```bash
cd ELDK2027/deck/build
npm install                      # pptxgenjs, react-icons, react, react-dom, sharp
node art.js                      # only if you change the background art (also writes the site's copy)
node deck.js                     # writes ../../SlideDecks/The Agentic SOC - Experts Live Denmark 2027.pptx
```

`deck.js` writes the theme colours into the file when `PPTX_SKILL_DIR` points at a copy of the `apply_theme.js` helper. Without it, PowerPoint shows Office's stock palette for the scheme colours. If you edit the committed `.pptx` by hand, don't rebuild over it.

# Deck source

The deck in [`../SlideDecks/`](../SlideDecks/) is generated by
[`build/deck.js`](build/deck.js) with [pptxgenjs](https://gitbrains.github.io/PptxGenJS/).
It is a structured deck — theme, layouts with placeholders, sections, and speaker
notes on every slide — so it edits cleanly in PowerPoint too.

## Rebuild

```bash
cd WPNinjas2027/deck/build
npm install                      # pptxgenjs, react-icons, react, react-dom, sharp
node art.js                      # only if you change the background art or logo
node deck.js                     # writes ../../SlideDecks/Defender for Agents - WPNinjas US 2027.pptx
```

`deck.js` writes theme colours into the file when `PPTX_SKILL_DIR` points at a
copy of the `apply_theme.js` helper; without it PowerPoint shows Office's stock
palette for the scheme colours. If you edit the committed `.pptx` by hand
instead, don't rebuild over it.
